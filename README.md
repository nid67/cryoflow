# Valtway AI

**Predictive Cold Chain Logistics & Thermal Degradation Intelligence**

## 📌 The Problem

Every year, over $35 Billion in temperature-sensitive cargo (pharmaceutical vaccines, mRNA biologics, organic dairy, and quick-commerce produce) is lost due to thermal excursions in transit. Traditional cold chain systems only report historical temperature breaches *after* spoilage occurs.

## 🚀 The Core Innovation

**Valtway AI** predicts thermal degradation **before** irreversible spoilage happens and recommends real-time recovery actions (e.g., Re-route to cold hub, Nearest Warehouse, Priority Express, or Secondary Marketplace Liquidation).

## 🏗️ System Architecture & Technology Stack

The platform is designed with a modern, decoupled architecture:

- **Frontend:** React + Tailwind CSS (Vite)
  - Real-time Control Center Dashboard
  - Live Shipment Management
  - AI Prediction Engine UI
  - Interactive Decision Center
- **Backend (Designed to integrate with):** FastAPI Python REST API
  - Pydantic Schemas & Input Validation
  - AI Kinetic Degradation & Risk Service
  - Decision Center Action Execution Engine

## 💡 Key Features

- **Enterprise Dashboard:** Real-time telemetry monitoring for KPIs, financial loss prevented, and carbon footprint saved.
- **Shipment Management:** Robust CRUD operations for tracking vaccines, dairy, and perishables.
- **AI Thermal Prediction Engine:** Instantly calculates remaining shelf life, spoilage risk (%), health score, financial loss risk, and carbon impact based on temperature excursions.
- **Actionable Decision Center:** Allows operators to trigger automated recovery actions that restore thermal equilibrium and resolve alerts instantly.

## ⚙️ Getting Started

### Prerequisites
- Node.js (v18+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/nid67/valtway.git
   cd valtway
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
